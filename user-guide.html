User Guide

The User Guide covers all aspects of GeoEq, from basic soil property calculations to advanced particle size analysis and professional publication-ready plots. Each section documents every function argument, lists all output dictionary keys, and provides working code examples you can copy directly into your own notebooks or scripts.

GeoEq is designed to be lightweight, traceable, and reliable. Every formula is cross-referenced with standard geotechnical textbooks: Das (2018), Holtz & Kovacs, and ASTM / BS / IS standards.

The guide follows the same chapter structure as Principles of Geotechnical Engineering by Braja Das: Chapter 2 covers Particle Size Analysis, and Chapter 3 covers Soil Properties and Classification.

Particle Size Analysis

GeoEq includes a complete, laboratory-grade particle size analysis suite. It covers two distinct test methods — Sieve Analysis for coarse-grained soils and Hydrometer Analysis for fine-grained soils — and is designed so that results from both can be combined into a single, continuous grain size distribution curve.

1. Sieve Analysis — ge.sieve_ana()

This function accepts two lists — the sieve sizes and the mass retained on each sieve — and automatically converts them to a percent-finer-by-mass distribution using one of three internationally recognised standards.

Function Signature

python
ge.sieve_ana(
    opening,           # list of sieve sizes (designations OR mm floats)
    mass_retained,     # list of masses in grams retained on each sieve
    standard="ASTM",  # standard: "ASTM", "BS", or "IS"
    total_mass=None    # total specimen mass (g). If None, sum of retained masses is used
)

Sieve Designation Formats

You can mix and match designation styles and GeoEq will resolve them correctly. All of the following are valid inputs:

python
# ASTM designations (number sieves and inch fractions)
opening = ["3/4\"", "3/8\"", "#4", "#10", "#40", "#100", "#200"]

# BS sieve designations (sizes in mm)
opening = ["20mm", "10mm", "5mm", "2mm", "600um", "212um", "75um"]

# Raw mm values (any standard)
opening = [19.0, 9.5, 4.75, 2.0, 0.425, 0.075]

Return Value (Dictionary)

The function returns a Python dictionary with the following keys, all as NumPy arrays:

python
res = ge.sieve_ana(["#4", "#10", "#40", "#200"], [10, 25, 40, 15], total_mass=100)

res["diameter"]          # Nominal opening in mm  → [4.75, 2.0, 0.425, 0.075]
res["opening"]           # Alias for diameter (same values)
res["mass_retained"]     # Mass on each sieve (g)
res["percent_retained"]  # % of total mass on each sieve
res["cumulative_retained"]# Cumulative % retained
res["percent_finer"]     # % passing (finer) — this is your Y-axis data
res["total_mass"]        # Total specimen mass used for calculations

2. Hydrometer Analysis — ge.hydro_ana()

Implements the full ASTM D7928 sedimentation analysis. Raw readings from a standard 152H hydrometer are corrected for meniscus, temperature, and dispersing agent, then converted to equivalent particle diameters using Stokes' Law.

Function Signature

python
ge.hydro_ana(
    reading,          # list of raw hydrometer readings (top of meniscus)
    time,             # list of elapsed times in minutes
    T,                # temperature of suspension (°C)
    Gs=2.65,         # specific gravity of soil solids (default: 2.65)
    Ws=50.0,         # dry mass of soil specimen in grams (default: 50g)
    Fm=1.0,          # meniscus correction (default: 1.0 for 152H)
    Fz=0.0,          # zero correction (dispersing agent correction)
)

Return Value (Dictionary)

python
h_res = ge.hydro_ana([52, 45, 38, 28], [1, 15, 60, 1440], T=22.0, Ws=50.0)

h_res["diameter"]       # Equivalent particle diameter D (mm) via Stokes' Law
h_res["percent_finer"]  # Percent finer (%) — corrected P value
h_res["reading"]        # Corrected hydrometer readings (R_c)
h_res["depth"]          # Effective depth L (cm) for each reading
h_res["time"]           # Elapsed time (minutes)

3. Combining Sieve + Hydrometer

Once you have results from both tests, simply pass them as a dictionary to the plotting function. GeoEq automatically merges the datasets and calculates parameters across the full range.

python
# Run both tests
s_res = ge.sieve_ana(["#4", "#10", "#40", "#200"], [10, 25, 40, 15])
h_res = ge.hydro_ana([50, 42, 30, 18], [1, 15, 60, 1440], T=22.0)

# Pass both to plot — they are stitched into one continuous curve
ge.grain_size_plot({"Sieve": s_res, "Hydrometer": h_res}, smooth=True)

Advanced Plotting — ge.grain_size_plot()

This is the most feature-rich function in the package. It generates a fully professional, publication-quality, semi-logarithmic grain size distribution curve. Internally it wraps Matplotlib, so every Matplotlib line keyword argument works — colour, linewidth, linestyle, markersize, alpha, and more.

Full Function Signature

python
ge.grain_size_plot(
    data,              # dict with keys 'diameter' & 'percent_finer'  — OR —
                       # dict of named datasets: {"Sieve": s_res, "Hydro": h_res}
    smooth=False,     # bool — enables high-res PCHIP smooth curve (1000 points)
    annotation=False, # bool — show a legend labelling each data source
    D_para=True,      # bool — draw red dotted projection lines for D10/D30/D60
    Cu_para=True,     # bool — show Uniformity Coefficient Cᵤ in the parameter box
    Cc_para=True,     # bool — show Coefficient of Curvature Cᶜ in the parameter box
    param_pos="top right", # str or (x, y) — position of the parameter info box
    save_as=None,     # str — filename to save: 'plot.png', 'report.pdf', 'figure.svg'
    ax=None,          # matplotlib Axes — embed into an existing figure
    **kwargs           # any Matplotlib line2D keyword (see table below)
)

Matplotlib Pass-Through Arguments (**kwargs)

Because GeoEq uses Matplotlib internally, all standard line styling arguments are accepted. This is the same as calling ax.plot() directly. Common examples:

python
ge.grain_size_plot(
    data,
    smooth=True,
    # --- Line Style ---
    color='#1e4d8f',   # any hex, name, or rgb tuple
    linewidth=1.8,      # line thickness
    linestyle='--',    # '-', '--', ':', '-.'
    alpha=0.85,         # transparency (0.0–1.0)
    # --- Markers ---
    marker='o',        # 'o', 's', '^', '*', 'D', 'v', 'none', ...
    markersize=6,      # size of each marker
    markerfacecolor='white',  # fill color of marker
    markeredgecolor='blue',   # border color of marker
    markeredgewidth=1.2,      # border thickness
    # --- Save ---
    save_as='report.pdf'  # .png, .pdf, .svg, .eps — all formats supported
)

Parameter Box Position (param_pos)

The box that shows D₁₀, D₃₀, D₆₀, Cᵤ, and Cᶜ can be placed anywhere. Use a keyword string or a precise (x, y) position in axes-fraction coordinates (0.0 = left/bottom, 1.0 = right/top):

python
# Keyword positions
param_pos="top right"    # default — upper right corner
param_pos="top left"     # upper left corner
param_pos="bottom right" # lower right corner
param_pos="bottom left"  # lower left corner

# Precise (x, y) control in axes-fraction coordinates
param_pos=(0.5, 0.8)  # centre of the plot, 80% up

Embedding in Your Own Figure

Because grain_size_plot() accepts an ax argument and returns the fig object, you can embed it into multi-panel scientific figures or add custom annotations after the fact:

python
import matplotlib.pyplot as plt
import geoeq as ge

# Create your own figure with multiple panels
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(18, 7))

# Embed GeoEq plot in the left panel
ge.grain_size_plot(s_res, ax=ax1, smooth=True, color='blue')

# Add your own plot in the right panel
ax2.plot(depth, settlement)
ax2.set_title("Settlement Curve")

# Add a custom annotation to the grain size plot after the fact
ax1.axhline(50, color='purple', linestyle='--', label='D₅₀')

plt.savefig('combined_report.pdf', bbox_inches='tight', dpi=300)

Saving to Publication Formats

The save_as argument routes directly to Matplotlib's savefig(), so all formats are supported. GeoEq always saves at 300 DPI with a tight bounding box — ideal for journals and reports.

python
ge.grain_size_plot(data, save_as="figure.png")  # raster, 300 DPI
ge.grain_size_plot(data, save_as="figure.svg")  # vector — scalable
ge.grain_size_plot(data, save_as="figure.pdf")  # vector — best for LaTeX
ge.grain_size_plot(data, save_as="figure.eps")  # vector — legacy journals

Parameter Extraction

You can extract geotechnical parameters from any result dictionary — from sieve data, hydrometer data, or a merged combined dataset. All five functions use log-linear interpolation, which is the industry standard for grain size parameter calculations.

Available Functions

python
# Diameter at which N% of soil is finer (mm)
d10 = ge.grain_d10(res)  # effective size
d30 = ge.grain_d30(res)  # used for Cc calculation
d60 = ge.grain_d60(res)  # controlling size

# Uniformity Coefficient — Cᵤ = D₆₀ / D₁₀
# Well-graded if Cᵤ ≥ 4 (gravels) or Cᵤ ≥ 6 (sands)
cu = ge.grain_Cu(res)

# Coefficient of Curvature — Cᶜ = D₃₀² / (D₁₀ × D₆₀)
# Well-graded if 1 ≤ Cᶜ ≤ 3
cc = ge.grain_Cc(res)

print(f"D10={d10:.3f} mm,  D30={d30:.3f} mm,  D60={d60:.3f} mm")
print(f"Cᵤ = {cu:.2f}  →  {'Well-graded' if cu >= 6 else 'Poorly-graded'}")
print(f"Cᶜ = {cc:.2f}  →  {'Within range' if 1 <= cc <= 3 else 'Outside range'}")

Chapter 3 — Void Ratio, Porosity & Specific Gravity

Void ratio (e) and porosity (n) describe the relative volume of voids in a soil. GeoEq provides two symmetrical functions — ge.void_ratio() and ge.porosity() — that accept different input combinations and automatically resolve the correct path.

1. Void Ratio — ge.void_ratio()

Computes void ratio from any physically meaningful input combination. All inputs are validated to be within geotechnically possible ranges.

python
ge.void_ratio(
    n=None,        # porosity (0 < n < 1)
    Vv=None,       # volume of voids (m³ or any consistent unit)
    Vs=None,       # volume of solids
    Vt=None,       # total volume (Vt = Vv + Vs)
)

# From porosity: e = n / (1 - n)
e = ge.void_ratio(n=0.42)
print(f"e = {e:.3f}")  # → e = 0.724

# From volumes: e = Vv / Vs
e2 = ge.void_ratio(Vv=0.30, Vs=0.70)
print(f"e = {e2:.3f}")  # → e = 0.429

2. Porosity — ge.porosity()

python
ge.porosity(
    e=None,        # void ratio (e > 0)
    Vv=None,       # volume of voids
    Vt=None,       # total volume
)

# From void ratio: n = e / (1 + e)
n = ge.porosity(e=0.72)
print(f"n = {n:.3f}")  # → n = 0.419

# From volumes: n = Vv / Vt
n2 = ge.porosity(Vv=0.28, Vt=1.0)
print(f"n = {n2:.3f}")  # → n = 0.280

Specific Gravity — ge.specific_gravity()

Computes the specific gravity of soil solids from measured mass and volume. This is the fundamental property used in most phase-relation calculations.

Function Signature

python
ge.specific_gravity(
    Ms,               # mass of solids (grams)
    Vs,               # volume of solids (cm3)
)

Usage

python
# Gs = Ms / (Vs * rho_w)  where rho_w = 1.0 g/cm3
Gs = ge.specific_gravity(Ms=265.0, Vs=100.0)
print(f"Gs = {Gs}")  # --> Gs = 2.65

# Works with numpy arrays too
import numpy as np
Gs_arr = ge.specific_gravity(Ms=np.array([265, 270, 275]), Vs=np.array([100, 100, 100]))
print(Gs_arr)  # --> [2.65, 2.70, 2.75]

Unit Weight & Density — ge.density()

Computing dry, saturated, bulk, and submerged unit weights is one of the most common tasks in geotechnical practice. GeoEq unifies all of these into a single smart function with a kind argument. It also supports multiple output unit systems — so you can request kN/m³ for European standards or pcf for American practice with no manual conversion.

Function Signature

python
ge.density(
    Gs=None,       # specific gravity of solids (dimensionless, typically 2.60–2.80)
    e=None,        # void ratio
    w=None,        # water content (decimal, e.g. 0.18 for 18%)
    S=None,        # degree of saturation (0.0–1.0)
    mass=None,     # total mass of sample (kg or g)
    volume=None,   # total volume of sample
    kind="bulk",   # "bulk", "dry", "saturated", or "submerged"
    unit="kN/m3", # output unit: "kN/m3", "kPa/m", "kg/m3", "g/cm3", "pcf"
)

All Four Density Types

python
# Dry unit weight: γd = (Gs × γw) / (1 + e)
gamma_d   = ge.density(Gs=2.65, e=0.72, kind="dry",       unit="kN/m3")

# Saturated unit weight: γsat = (Gs + e) × γw / (1 + e)
gamma_sat = ge.density(Gs=2.65, e=0.72, kind="saturated",  unit="kN/m3")

# Submerged / buoyant unit weight: γ' = γsat - γw
gamma_sub = ge.density(Gs=2.65, e=0.72, kind="submerged", unit="kN/m3")

# Bulk unit weight: γ = (Gs + S×e) × γw / (1 + e)
gamma_b   = ge.density(Gs=2.65, e=0.72, S=0.80, kind="bulk",       unit="kN/m3")

print(f"γd={gamma_d:.2f}  γsat={gamma_sat:.2f}  γ'={gamma_sub:.2f}  γ={gamma_b:.2f} kN/m³")

# Direct from mass and volume (any unit system)
gamma_pcf = ge.density(mass=50, volume=0.028, unit="pcf")
print(f"Bulk density = {gamma_pcf:.1f} pcf")

Unit Conversion Quick Reference

The unit argument accepts any of the following strings. GeoEq automatically applies the correct water unit weight (9.81 kN/m³ or 62.4 pcf) in its calculations:

python
# SI units
unit="kN/m3"   # kilonewtons per cubic metre  (most common in geotechnical practice)
unit="kPa/m"   # same magnitude, different notation (useful for stress gradients)
unit="kg/m3"   # kilograms per cubic metre
unit="g/cm3"   # grams per cubic centimetre (same as geecific gravity scale)

# Imperial units
unit="pcf"     # pounds per cubic foot (lbf/ft³)

Atterberg Limits — ge.atterberg()

Atterberg limits define the water content boundaries at which fine-grained soil transitions between solid, semi-solid, plastic, and liquid states. GeoEq computes the Plasticity Index (PI), Liquidity Index (LI), and Consistency Index (CI) from a single unified function using the kind argument.

Function Signature

python
ge.atterberg(
    LL,            # Liquid Limit (%)
    PL,            # Plastic Limit (%)
    w=None,        # current water content (%) — required for LI and CI
    kind="PI",    # "PI", "LI", "CI", or "all"
)

Usage — All Return Modes

python
# Plasticity Index: PI = LL - PL
PI = ge.atterberg(LL=48, PL=22, kind="PI")
print(f"PI = {PI}")   # → PI = 26

# Liquidity Index: LI = (w - PL) / (LL - PL)
# LI < 0 → Solid, 0–1 → Plastic, > 1 → Liquid
LI = ge.atterberg(LL=48, PL=22, w=35, kind="LI")
print(f"LI = {LI:.2f}")  # → LI = 0.50

# Consistency Index: CI = (LL - w) / (LL - PL) = 1 - LI
CI = ge.atterberg(LL=48, PL=22, w=35, kind="CI")
print(f"CI = {CI:.2f}")  # → CI = 0.50

# All at once — returns a dictionary
result = ge.atterberg(LL=48, PL=22, w=35, kind="all")
result["PI"]  # → 26
result["LI"]  # → 0.50
result["CI"]  # → 0.50

Index Properties — Activity, Sensitivity & Liquidity Index

These standalone functions compute common index properties for fine-grained soils. Each accepts scalars or numpy arrays.

1. Activity — ge.activity()

Measures how reactive a clay is based on its plasticity relative to its clay-size fraction. Defined by Skempton (1953).

python
# Activity = PI / clay_fraction(%)
# Classification: A < 0.75 Inactive, 0.75-1.25 Normal, > 1.25 Active

A = ge.activity(PI=30, clay_fraction=40)
print(f"Activity = {A}")  # --> 0.75 (Inactive/Normal boundary)

A2 = ge.activity(PI=50, clay_fraction=20)
print(f"Activity = {A2}")  # --> 2.5 (Active clay)

2. Sensitivity — ge.sensitivity()

Ratio of undisturbed to remolded undrained shear strength. Indicates how much strength a clay loses when disturbed.

python
# St = Su(undisturbed) / Su(remolded)
# Classification: 1 Insensitive, 1-4 Medium, 4-8 Sensitive, >8 Quick clay

St = ge.sensitivity(Su_undisturbed=100, Su_remolded=25)
print(f"Sensitivity = {St}")  # --> 4.0 (Sensitive)

St2 = ge.sensitivity(Su_undisturbed=80, Su_remolded=5)
print(f"Sensitivity = {St2}")  # --> 16.0 (Quick clay!)

3. Liquidity Index (standalone) — ge.liquidity_index()

Convenience function that computes LI directly without the atterberg() wrapper. Useful when you already know PI.

python
# LI = (w - PL) / PI
# LI < 0: semi-solid  |  0-1: plastic  |  > 1: liquid

LI = ge.liquidity_index(w=35, PL=22, PI=26)
print(f"LI = {LI:.2f}")  # --> 0.50 (plastic range)

# Works with arrays for batch processing
import numpy as np
w_arr = np.array([22, 35, 48])
LI_arr = ge.liquidity_index(w=w_arr, PL=22, PI=26)
print(LI_arr)  # --> [0.0, 0.5, 1.0]

Relative Density — ge.relative_density()

Relative density (Dr) measures how densely packed a granular soil is relative to its loosest and densest states. GeoEq supports two calculation paths via the kind argument — one based on void ratio limits and one based on dry density limits.

Function Signature

python
ge.relative_density(
    e=None,        # current void ratio (used when kind='void')
    e_max=None,    # void ratio at loosest state (maximum voids)
    e_min=None,    # void ratio at densest state (minimum voids)
    rho=None,      # current dry density (used when kind='density')
    rho_max=None,  # maximum dry density (densest state)
    rho_min=None,  # minimum dry density (loosest state)
    kind="void",  # "void" or "density"
)

Usage

python
# From void ratio: Dr = (e_max - e) / (e_max - e_min)
Dr_e = ge.relative_density(e=0.60, e_max=0.85, e_min=0.45, kind="void")
print(f"Dr = {Dr_e:.1%}")  # → Dr = 62.5%  (Medium dense)

# From dry density: Dr = (ρd,max/ρd,min) × (ρd - ρd,min) / (ρd,max - ρd,min) × 1/ρd
Dr_rho = ge.relative_density(rho=1560, rho_max=1720, rho_min=1380, kind="density")
print(f"Dr = {Dr_rho:.1%}")  # → Dr = 51.1%  (Medium dense)

# Interpretation of Dr values (Das, 2018):
# Dr < 15%   → Very Loose
# 15–50%     → Loose
# 50–70%     → Medium Dense
# 70–85%     → Dense
# Dr > 85%   → Very Dense

Phase Relations — ge.saturation() & ge.water_content()

These functions compute the degree of saturation and water content from various combinations of phase variables. GeoEq uses lazy resolution — you only need to provide the inputs you have measured in the lab, and it finds the correct formula automatically.

1. Degree of Saturation — ge.saturation()

python
ge.saturation(
    w=None,    # water content (decimal)
    Gs=None,   # specific gravity of solids
    e=None,    # void ratio
    Vw=None,   # volume of water
    Vv=None,   # volume of voids
)

# From phase parameters: S = (w × Gs) / e
S = ge.saturation(w=0.18, Gs=2.65, e=0.72)
print(f"S = {S:.1%}")   # → S = 66.3%

# From volumes: S = Vw / Vv
S2 = ge.saturation(Vw=0.25, Vv=0.40)
print(f"S = {S2:.1%}")  # → S = 62.5%

# Typical interpretation:
# S = 0%   → Completely dry
# S = 100% → Fully saturated (all voids filled with water)

2. Water Content — ge.water_content()

python
ge.water_content(
    Mw=None,   # mass of water (g or kg)
    Ms=None,   # mass of dry solids
    S=None,    # degree of saturation (0–1)
    Gs=None,   # specific gravity
    e=None,    # void ratio
)

# From lab measurements: w = Mw / Ms
w = ge.water_content(Mw=18.5, Ms=102.0)
print(f"w = {w:.1%}")   # → w = 18.1%

# From phase parameters: w = (S × e) / Gs
w2 = ge.water_content(S=0.80, e=0.72, Gs=2.65)
print(f"w = {w2:.1%}")  # → w = 21.7%

Chapter 4 — USCS Classification

The Unified Soil Classification System (USCS) per ASTM D2487-17 classifies soils into standardized groups based on grain size distribution and Atterberg limits. GeoEq implements the full ASTM flowchart including dual symbols for the 5-12% fines transition zone.

Function Signature

python
ge.classify_uscs(
    LL=None,         # Liquid Limit (%)
    PL=None,         # Plastic Limit (%)
    gravel=0.0,      # % retained on No. 4 sieve (4.75 mm)
    sand=0.0,        # % passing No. 4, retained on No. 200
    fines=None,       # % passing No. 200 (auto-computed if omitted)
    Cu=None,          # Uniformity Coefficient (required when fines < 12%)
    Cc=None,          # Coefficient of Curvature (required when fines < 12%)
    organic=False,    # True if oven-dried LL < 75% of non-dried LL
)
# Returns: {'symbol': 'CH', 'name': 'Fat clay'}

Usage Examples

python
# Well-graded sand (fines < 5%, Cu >= 6, 1 <= Cc <= 3)
cls = ge.classify_uscs(gravel=4, sand=92, fines=4, Cu=8, Cc=2)
print(cls)  # {'symbol': 'SW', 'name': 'Well-graded sand'}

# Fat clay (LL >= 50, above A-line)
cls = ge.classify_uscs(LL=70, PL=30, fines=80, gravel=5, sand=15)
print(cls)  # {'symbol': 'CH', 'name': 'Fat clay'}

# Dual symbol (5-12% fines zone)
cls = ge.classify_uscs(gravel=3, sand=87, fines=10, Cu=7, Cc=2, LL=25, PL=22)
print(cls)  # {'symbol': 'SW-SM', 'name': 'Well-graded sand with silt'}

AASHTO Classification

The AASHTO system (M145) classifies soils for highway construction. GeoEq implements the left-to-right elimination procedure from Das (2021) Table 4.4, including automatic Group Index calculation.

Function Signature

python
ge.classify_aashto(
    LL,              # Liquid Limit (%)
    PL,              # Plastic Limit (%)
    gravel=0.0,      # % retained on No. 10 sieve
    sand=0.0,        # % passing No. 10, retained on No. 200
    fines=None,       # % passing No. 200
)
# Returns: {'group': 'A-7-6', 'group_index': 13, 'description': 'Clayey soils'}

Usage Examples

python
# Clayey soil
aas = ge.classify_aashto(LL=45, PL=22, fines=60)
print(aas)
# {'group': 'A-7-6', 'group_index': 11, 'description': 'Clayey soils'}

# Silty soil
aas = ge.classify_aashto(LL=30, PL=25, fines=60)
print(aas)
# {'group': 'A-4', 'group_index': ..., 'description': 'Silty soils'}

# Group Index formula:
# GI = (F-35)[0.2+0.005(LL-40)] + 0.01(F-15)(PI-10)

Plasticity Chart — ge.plasticity_chart()

Plots the Casagrande plasticity chart with the A-line (PI = 0.73(LL-20)) and U-line (PI = 0.9(LL-8)). Optionally plots soil samples for visual USCS classification.

Function Signature

python
ge.plasticity_chart(
    LL=None,          # Liquid Limit(s) for data points
    PL=None,          # Plastic Limit(s) for data points

The ge.profile module ties lab data, site investigation, and design calculations together. A Soil dataclass holds one layer's engineering properties; a SoilProfile stacks them and integrates unit weights downward to produce total, pore, and effective stress at any depth.

1. The Soil layer — ge.Soil()

Plain dataclass — only name is required. Sensible defaults for everything else.

    gamma_sat=None,    # saturated unit weight (defaults to gamma + 1.5)
    phi=30,            # effective friction angle (°)
    c=0,               # effective cohesion (kPa)
    e=None, Gs=2.70,   # void ratio, specific gravity
    k=None,            # hydraulic conductivity (m/s)

    Cc=None, Cr=None, OCR=1.0,

)

Method .gamma_effective() returns the submerged unit weight γ′ = γsat − γw.

2. The SoilProfile — ge.SoilProfile()

An ordered list of (top, bot, Soil) tuples plus an optional water table depth. Layers must be contiguous (no gaps, no overlaps) and ordered top-to-bottom (positive z = downward).

Stress at depth — Das Eq. 5.1–5.5

For a depth z, the profile integrates unit weights downward using γ above the water table and γsat below it. Pore pressure is hydrostatic: u = γw·max(0, z − zw). Effective stress is Terzaghi's principle: σ′ = σ − u.

sand = ge.Soil("Dense Sand", gamma=19, gamma_sat=20.5, phi=35)

p = ge.SoilProfile([
    (0, 2,  ge.Soil("Fill", gamma=18)),
    (2, 8,  clay),
    (8, 20, sand),
], water_table=1.5)

p.stress_at(10)
# → {'sigma': 188.0, 'u': 78.48, 'sigma_eff': 109.52}

p.total_stress([2, 5, 10])      # vectorised — accepts arrays
p.layer_at(5).name             # → 'Soft Clay'

Behind the Code

GeoEq is fully traceable to published standards and textbooks. Every formula is cross-referenced with Das (2018), Holtz & Kovacs, and ASTM standards.

Grain Size Formulas

Equivalent Particle Diameter (Stokes' Law):
D = √(18 η L / ((Gs − Gw) γw t))

Percent Finer (Hydrometer):
P = (a × Rc) / Ws × 100 , where a = Gs / (Gs − 1)

Uniformity Coefficient:
Cᵤ = D₆₀ / D₁₀

Coefficient of Curvature:
Cᶜ = D₃₀² / (D₁₀ × D₆₀)

Soil Phase Formulas

Dry Unit Weight: γd = (Gs γw) / (1 + e)  [Das Eq. 3.13]

Saturated Unit Weight: γsat = (Gs + e) γw / (1 + e)  [Das Eq. 3.15]

Submerged Unit Weight: γ' = γsat − γw  [Das Eq. 3.16]

Porosity to Void Ratio: e = n / (1 − n)  [Das Eq. 3.5]

Degree of Saturation: S = (w × Gs) / e  [Das Eq. 3.10]

Relative Density: Dr = (emax − e) / (emax − emin)  [Das Eq. 3.22]

Index Properties

Activity: A = PI / CF  [Skempton, 1953]

Sensitivity: St = Su(und) / Su(rem)  [Das Ch. 4]

Liquidity Index: LI = (w − PL) / PI  [Das Ch. 4]

Classification

A-line: PI = 0.73 (LL − 20)  [Casagrande, Das Fig. 4.8]

U-line: PI = 0.9 (LL − 8)  [Das Fig. 4.8]

AASHTO Group Index: GI = (F−35)[0.2+0.005(LL−40)] + 0.01(F−15)(PI−10)  [AASHTO M145]

Shear Strength (Das Ch. 8)

Mohr–Coulomb: τf = c + σ' tan φ  [Das Eq. 8.3]

Unconfined Shear Strength: Su = qu / 2  [Das Eq. 8.9]

Consolidation (Das Ch. 7)

Compression Index: Cc = (e₁ − e₂) / log(σ'₂ / σ'₁)  [Das Eq. 7.9]

Terzaghi Correlation: Cc = 0.009 (LL − 10)  [Das Table 7.3]

Time Factor (50%): cv = T₅₀ Hdr² / t₅₀ , T₅₀ = 0.197  [Das Eq. 7.22]

Time Factor (90%): cv = T₉₀ Hdr² / t₉₀ , T₉₀ = 0.848  [Das Eq. 7.23]

Compaction (Das Ch. 5)

Zero Air Voids: γd = Gs γw / (1 + w Gs)  [Das Eq. 5.12]

Relative Compaction: RC (%) = γd / γd,max × 100

Permeability (Das Ch. 5)

Constant-Head: k = Q L / (A h t)  [Das Eq. 5.11]

Falling-Head: k = (a L / A t) ln(h₁ / h₂)  [Das Eq. 5.13]

CBR (Das Ch. 5)

CBR: CBR (%) = (Ptest / Pstandard) × 100  [ASTM D1883]

SPT Corrections

Energy Correction: N₆₀ = N × (ER/60) × Cb × Cs × Cr  [Skempton, 1986]

Overburden (Liao & Whitman): CN = √(pa / σ'v)  [1986]

Hatanaka Friction Angle: φ' = √(20 N₁₆₀) + 20  [1996]

Hara Su: Su = 29 × N₆₀0.72 kPa  [1974]

Meyerhof Dr: Dr (%) = √(N₁₆₀ / 41) × 100  [1957]

CPT Correlations

Normalized Resistance: Qt = (qt − σv0) / σ'v0  [Robertson, 2009]

SBT Index: Ic = √[(3.47 − log Qt)² + (log Fr + 1.22)²]  [Robertson, 2009]

Friction Angle: φ' = arctan[0.1 + 0.38 log(qt/σ'v)]  [Robertson & Campanella, 1983]

Su: Su = (qt − σv0) / Nkt  [Lunne et al., 1997]

Baldi Dr: Dr = (1/C₂) ln[qc / (C₀ σ'vC₁)]  [1986]

Vane Shear

Su from Torque: Su = T / [π(D²H/2 + D³/6)]  [ASTM D2573]

Bjerrum Correction: μ = 1.7 − 0.54 log₁₀(PI)  [1972]

Pressuremeter

Em: Em = 2(1+ν)(V₀+Vm) Δp/ΔV  [Ménard, 1956]

Bearing: qu = σv0 + k(pL − p₀)  [Ménard, 1963]

Plate Load Test

Subgrade Modulus: ks = q / δ  [Terzaghi, 1955]

Settlement (sand): Sf/Sp = [Bf(Bp+0.3) / (Bp(Bf+0.3))]²  [Terzaghi & Peck, 1967]

Pile Load Tests

Davisson Offset: Δoffset = PL/AE + (0.15 + D/120) in.  [1972]

Chin: Qu = 1/C₁ (slope of Δ/Q vs Δ)  [1970]

Hansen 80%: Qu = 1/(2√(ab))  [1963]

Hiley: Qu = Whη / (s + c/2)  [1925]

Case Method: Rs = ½[(1−Jc)(F₁+Zv₁) + (1+Jc)(F₂−Zv₂)]  [Goble et al., 1975]

Field Permeability

Hvorslev: k = r² ln(Le/R) / (2 Le T₀)  [1951]

Thiem (confined): k = Q ln(r₂/r₁) / (2π H (h₂−h₁))  [1906]

Thiem (unconfined): k = Q ln(r₂/r₁) / (π (h₂²−h₁²))  [1906]

DCP–CBR

Webster: log₁₀(CBR) = 1.12 − 0.39 log₁₀(DCPI)  [USACE, 1992]

TRL: log₁₀(CBR) = 2.48 − 1.057 log₁₀(DCPI)  [1993]
